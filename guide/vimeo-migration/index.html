VIMEO MIGRATION / 5 STEPS

VimeoからGumletへ動画をインポートする完全移行ガイド

ローカルPCへのダウンロード不要。クラウド間で直接移行し、既存サイトの埋め込みURLを差し替えるための手順です。

CONTENTS

  1. 移行前の前提条件
  2. インポート手順（5ステップ）
  3. 移行データ一覧
  4. 埋め込みコード差し替え

結論：VimeoからGumletへの動画移行は、ローカルPCへのダウンロードや再アップロードを行わず、Gumlet管理画面からVimeoアカウントをAPI連携するだけでクラウド間直接移行が完了します。さらにGumletはVimeoの動画IDを保持するため、既存Webサイトの埋め込みURLのドメイン差し替えのみで移行作業を完結できます。

1. 移行前に確認すべき前提条件

  • Vimeoのアカウント条件: VimeoのStandard、Pro、Business、またはEnterpriseなどの有料プランが必要です。（※Vimeo側のAPI制限により、Freeアカウントからは直接インポートできません）
  • Gumletのアカウント条件: Gumletの有料アカウント（または移行機能が有効なトライアルアカウント）が必要です。
Gumletアカウントを確認する ↗

2. VimeoからGumletへのインポート手順（5ステップ）

ステップ1：GumletダッシュボードでVimeo連携を選択

Gumletの管理画面にログインし、左側メニューまたは動画一覧画面の右上にある「Upload & Import」をクリックし、「Import from Vimeo」（または Import タブ）を選択します。

ステップ2：Vimeoアカウントの認証・連携

Vimeoの連携画面が表示されたら「Connect Vimeo」をクリックします。Vimeoの認証ポップアップが開くので、Gumletへのアクセス許可を承認（Authorize）します。

ステップ3：移行先のコレクション（フォルダ）を指定

動画を整理・保存するGumlet側の「Destination Workspace / Collection」を選択します。用途別（会員限定、LP用、研修用など）にあらかじめコレクションを作成しておくと管理がスムーズです。

ステップ4：移行する動画・フォルダの選択

Vimeo内の動画一覧およびフォルダ階層が読み込まれます。

  • 全動画を一括移行する場合はルートフォルダにチェック
  • 特定の動画のみを移行する場合は対象ファイルに個別チェック
    選択後、「Import Videos」をクリックします。

ステップ5：処理設定（Processing Settings）の確認と実行

ポップアップで取り込み時の処理オプションを設定します。

  • DRM Protection: 著作権保護・暗号化配信が必要な場合は有効化
  • MP4 Download: 視聴者にダウンロードを許可するかどうか
  • AI Subtitles / Summaries: 多言語字幕や要約の自動生成
    設定を確認後、「Save & Start Import」をクリックすれば移行処理が開始されます。

処理中の動作

移行はクラウドサーバー間でバックグラウンド実行されます。ブラウザやPCを閉じても処理は継続し、完了後に登録メールアドレスへレポート（成功・スキップ件数）が届きます。

3. 移行されるデータ・引き継がれないデータ一覧

VimeoからGumletへの移行データ一覧
項目移行可否詳細・対応方針
動画本体（ソース画質）○元の最高品質ファイルがそのまま転送され、Gumlet側で最適エンコード
動画タイトル / 概要欄○Vimeoで設定していたテキスト情報が引き継がれる
カスタムサムネイル○Vimeoで公開設定されていたポスター画像が自動適用
Vimeo Video ID○元動画の数値IDがGumlet側でも識別子として保持される
フォルダ構造○同名コレクションとして整理可能
プライバシー / 制限設定×ドメイン制限やパスワード保護はGumlet管理画面で再設定が必要
チャプター設定×引き継がれないため、Gumlet側でタイムスタンプを再指定
過去のアナリティクス×視聴回数や視聴維持率の履歴データは移行不可

4. 既存Webサイトの埋め込みコード差し替え

GumletはVimeoの元動画ID（例: 123456789）をそのまま埋め込みURLのIDとして引き継ぎます。既存サイトのソースコード内にあるiframeのURLドメインを書き換えるだけで再生可能です。

URLの置換ルール

  • 移行前（Vimeo）: https://player.vimeo.com/video/123456789
  • 移行後（Gumlet）: https://play.gumlet.io/embed/123456789

推奨埋め込みHTMLコード（レスポンシブ 16:9）

HTMLResponsive 16:9
<div class="video-frame">
  <iframe
    src="https://play.gumlet.io/embed/123456789"
    title="動画タイトル"
    loading="lazy"
    allow="autoplay; encrypted-media; fullscreen"
    allowfullscreen>
  </iframe>
</div>
